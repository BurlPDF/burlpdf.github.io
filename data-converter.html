FAQ

Is my data uploaded anywhere?

No. Parsing and conversion are done by JavaScript running in this page. Your text and files are never sent to a server, and the tool keeps working if you go offline after the page has loaded.

What JSON shape can I convert to CSV or TSV?

An array of objects, such as [{"name":"Asha","city":"Mumbai"}], or a single object, which becomes one row. Columns are the combined keys of all objects, so objects with missing keys leave empty cells.

How are nested objects and arrays handled?

With “Flatten nested objects” on, {"address":{"city":"Pune"}} becomes a column named address.city. Arrays, and nested objects when flattening is off, are written into the cell as JSON text.

Does my CSV or TSV need a header row?

Yes. The first row supplies the property names for the JSON output. Quoted values, commas or tabs inside quotes, doubled quotes and line breaks inside quotes are all supported.

Why did I get an error?

The message names the line or column where the problem was found. Common causes are a missing comma or quote in JSON, an unclosed quoted value in CSV, or a row with more values than the header has columns.

How large a file can I convert?

Files of several megabytes convert in a moment on most devices. Very large files depend on your device’s memory, since everything is processed locally.
