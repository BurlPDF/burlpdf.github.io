How it works

  1. Pick a mode. Use text mode for words and snippets, or file mode for images, PDFs, and any other file.
  2. Convert. Your browser reads the data, turns the bytes into Base64 characters, or reverses the process. Text is handled as UTF-8, so emoji and non-Latin scripts survive the round trip.
  3. Copy or download. Copy the result, or download a decoded file under the name you choose.

FAQ

Is my data uploaded anywhere?

No. All encoding and decoding happens in your browser with JavaScript. This page makes no network requests with your text or files, so it also works offline once loaded.

What is Base64?

Base64 represents binary data using 64 safe characters (A–Z, a–z, 0–9, + and /). It is commonly used to embed images in HTML or CSS, send attachments in email, and pass data through systems that only accept text.

Is Base64 encryption?

No. Anyone can decode Base64, so it gives no security. Do not use it to hide passwords or private information.

What is the difference between a Base64 string and a Data URL?

A Base64 string is only the encoded data. A Data URL adds a prefix such as data:image/png;base64, so browsers can use it directly in an img tag, a stylesheet, or a link.

Why does decoding fail?

The input probably contains characters outside the Base64 alphabet, is truncated, or decodes to bytes that are not valid text. This tool accepts line breaks, missing padding, and URL-safe characters. For binary content such as images, use the file mode instead of text mode.

Is there a file size limit?

There is no fixed limit, but Base64 output is about 33% larger than the original, and very large files can make your browser slow. Files under a few dozen megabytes work best.
