How it works

Metadata lives beside the pixels in an image file, not inside them. Redrawing the pixels onto a blank canvas leaves the metadata behind.

1. Load locally

Your image is decoded by the browser and drawn onto an HTML5 canvas. Nothing is sent over the network.

2. Re-encode

The canvas exports a brand-new JPG or PNG that contains only pixel data. EXIF, GPS, camera and software tags are not carried over.

3. Download

Preview the clean result, check the new file size, then save it. The file name gets a “-clean” suffix.

Frequently asked questions

What is EXIF data?

EXIF is information stored inside a photo file, such as the camera model, date and time, exposure settings and often the GPS coordinates of where the photo was taken. Sharing the original file can reveal more than you intend.

Is my image uploaded anywhere?

No. The image is read and processed entirely in your browser. You can confirm this by disconnecting from the internet after the page loads; the tool keeps working.

Will image quality change?

Output as PNG is lossless, so the pixels stay identical. Output as JPG re-compresses the image, which causes a small, usually invisible loss at high quality settings. WEBP and PNG inputs with transparency are placed on a white background when saved as JPG.

Why is the new file larger or smaller?

Removing metadata saves a few kilobytes, but re-encoding changes compression too. Converting a JPG to PNG usually makes the file much larger. Lowering the JPG quality slider makes it smaller.

Does it keep the photo’s orientation?

Yes. Browsers apply the EXIF rotation before drawing, so the clean image appears the right way up even though the rotation tag is removed.

Is there a size limit?

There is no limit set by this tool, but very large images (for example above 100 megapixels) may exceed your browser’s canvas limits, depending on your device and available memory.
